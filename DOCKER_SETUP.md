# Docker Setup Guide for Laravel 11

This guide will help you run your Laravel 11 application with Breeze in Docker.

## Prerequisites

- Docker Desktop installed (or Docker Engine + Docker Compose)
- At least 4GB RAM available for Docker
- Ports 8085, 3306, 8081, and 5173 available

## Quick Start

### 1. Build and Start Containers

```bash
docker-compose up -d --build
```

This will:
- Build the PHP 8.2 application container
- Start MySQL 8.0 database
- Start Nginx web server
- Start phpMyAdmin (optional)

### 2. Install Dependencies (First Time Only)

```bash
# Install PHP dependencies
docker-compose exec app composer install

# Install Node dependencies
docker-compose exec app npm install
```

### 3. Set Up Environment

```bash
# Copy environment file
docker-compose exec app cp .env.example .env

# Generate application key
docker-compose exec app php artisan key:generate

# Update .env file with database credentials:
# DB_HOST=mysql
# DB_DATABASE=laravel
# DB_USERNAME=user
# DB_PASSWORD=password
```

### 4. Run Migrations

```bash
docker-compose exec app php artisan migrate
```

### 5. Build Frontend Assets

**For Development:**
```bash
docker-compose exec app npm run dev
```

**For Production:**
```bash
docker-compose exec app npm run build
```

### 6. Set Permissions

```bash
docker-compose exec app chmod -R 775 storage bootstrap/cache
docker-compose exec app chown -R www-data:www-data storage bootstrap/cache
```

## Accessing the Application

- **Web Application**: http://localhost:8085
- **phpMyAdmin**: http://localhost:8081
- **MySQL**: localhost:3306 (user: `user`, password: `password`, database: `laravel`)

## Development with Vite (Hot Module Replacement)

For hot module replacement during development, you can use the Vite container:

```bash
# Start Vite dev server
docker-compose --profile dev up vite

# Or start everything including Vite
docker-compose --profile dev up
```

Then access your app at http://localhost:8085 with hot reload enabled.

## Common Docker Commands

### View Logs
```bash
# All services
docker-compose logs -f

# Specific service
docker-compose logs -f app
docker-compose logs -f nginx
docker-compose logs -f mysql
```

### Execute Commands in Container
```bash
# PHP Artisan commands
docker-compose exec app php artisan migrate
docker-compose exec app php artisan cache:clear

# Composer commands
docker-compose exec app composer install
docker-compose exec app composer update

# NPM commands
docker-compose exec app npm install
docker-compose exec app npm run dev
docker-compose exec app npm run build

# Shell access
docker-compose exec app bash
```

### Stop Containers
```bash
# Stop all containers
docker-compose stop

# Stop and remove containers
docker-compose down

# Stop and remove containers + volumes (⚠️ deletes database)
docker-compose down -v
```

### Restart Containers
```bash
docker-compose restart
```

## Installing Laravel Breeze in Docker

```bash
# Install Breeze
docker-compose exec app composer require laravel/breeze --dev

# Install Breeze scaffolding
docker-compose exec app php artisan breeze:install blade

# Install frontend dependencies
docker-compose exec app npm install

# Build assets
docker-compose exec app npm run dev
```

## Environment Configuration

Update your `.env` file with these Docker-specific settings:

```env
APP_NAME=TBMS
APP_ENV=local
APP_KEY=base64:... (generated by key:generate)
APP_DEBUG=true
APP_URL=http://localhost:8085

DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=laravel
DB_USERNAME=user
DB_PASSWORD=password

# For Vite (if using dev server)
VITE_APP_NAME="${APP_NAME}"
```

## Troubleshooting

### Port Already in Use
If ports are already in use, modify `docker-compose.yml`:
- Change `8085:80` to another port (e.g., `8086:80`)
- Change `3306:3306` to another port (e.g., `3307:3306`)

### Permission Denied Errors
```bash
docker-compose exec app chmod -R 775 storage bootstrap/cache
docker-compose exec app chown -R www-data:www-data storage bootstrap/cache
```

### Database Connection Issues
1. Check MySQL container is running: `docker-compose ps`
2. Verify credentials in `.env` match `docker-compose.yml`
3. Wait a few seconds after starting MySQL (it needs time to initialize)

### Composer/NPM Issues
```bash
# Clear Composer cache
docker-compose exec app composer clear-cache

# Remove vendor and reinstall
docker-compose exec app rm -rf vendor
docker-compose exec app composer install

# Remove node_modules and reinstall
docker-compose exec app rm -rf node_modules
docker-compose exec app npm install
```

### View Container Status
```bash
docker-compose ps
```

### Rebuild Containers
```bash
# Rebuild without cache
docker-compose build --no-cache

# Rebuild and restart
docker-compose up -d --build
```

## Production Deployment

For production, modify the Dockerfile to:
1. Use `composer install --no-dev --optimize-autoloader`
2. Run `npm run build` instead of `npm run dev`
3. Set `APP_ENV=production` and `APP_DEBUG=false` in `.env`
4. Use proper secrets management (not hardcoded passwords)

## Additional Services

You can add more services to `docker-compose.yml`:
- **Redis**: For caching and queues
- **Mailhog**: For testing emails
- **Elasticsearch**: For search functionality

Example Redis addition:
```yaml
redis:
  image: redis:7-alpine
  container_name: laravel_redis
  restart: unless-stopped
  networks:
    - laravel_network
```
